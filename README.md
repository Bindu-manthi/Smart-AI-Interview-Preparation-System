# AI Interview Preparation System

## Description

AI Interview Preparation System is a Django-based web application that helps users practice technical interviews using both text and voice interaction. The system generates random interview questions based on selected roles such as Python Developer, Java Developer, Data Analyst, Web Developer, Full Stack Developer, and AI/ML Engineer.

Users can answer questions through typing or voice input using speech recognition. The application also provides scores, feedback, and correct answers to improve interview preparation skills.

---

## Features

* Role-based interview questions
* Voice and text interview modes
* Automatic speech-to-text conversion
* Random score generation
* Feedback system
* Correct answer display
* Simple and user-friendly interface

---

## Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* Speech Recognition API

---

## Installation

```bash
pip install django
```

Run the project:

```bash
python manage.py runserver
```
